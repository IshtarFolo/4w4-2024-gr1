# Tp1: Club de Voyage
## Par Xavier Arbour

### Description
Ce site web est un projet scolaire pour le cours de 4w4. Le site web est un site de club de voyage. Il permet de voir les destinations offertes par le club de voyage. Il permet aussi de voir les détails de chaque destination. On peut également naviguer entre les différentes catégories de destinations. Pour le tp2, la page 404.php est implémentée et un fichier Sass, _404.scss, est fait pour cette même page
